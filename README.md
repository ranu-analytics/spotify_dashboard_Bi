
## 🎧 Spotify Analytics Dashboard

![Spotify Dashboard](spotify-dashboard.png)

---

###  Project Overview

This project showcases an **interactive Spotify Analytics Dashboard** built using Power BI. It analyzes song trends, artist popularity, and listening patterns to uncover meaningful insights from music data.

---

### Key Metrics
 Total Songs: **28K**
 Total Popularity Score: **2491K**
 Total Tracks: **282K**
 Short Songs Count: **10K**

---

### Dashboard Insights

**Top Artists by Popularity**
**Top Songs Performance**
**Songs Distribution by Year & Quarter**
**Monthly Trends of Song Releases**
**Album Type Analysis (Explicit vs Non-explicit)**
**Average Popularity by Album Type**

---

### Key Highlights

* Taylor Swift dominates artist popularity
* High concentration of songs in mid-year months
* Balanced distribution between explicit & non-explicit songs
* Strong performance of trending tracks
